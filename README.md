# CLINICA-DENTAL
El sistema de gestión para la clínica dental busca automatizar citas, historiales médicos, cobros, facturación y reportes, eliminando procesos manuales, reduciendo errores y mejorando la experiencia de pacientes y personal. Actualmente, se presentan problemas como pérdida de información, duplicidad de citas y dificultad para acceder a historiales clínicos, lo que retrasa la atención.
